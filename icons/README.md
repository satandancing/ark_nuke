# icons

PNG/SVG icons for Ark menus and the Nodes side toolbar.

- `init.py` already `pluginAddPath`s this folder.
- Gizmo icons are named `{GizmoBasename}.png` or `.svg` (Foundry resolves by filename on the plugin path).
- Category submenu icons: `3D.png`, `Channel.png`, `Draw.png`, `Filter.png`, `Image.png`, `Keyer.png`.
- Toolbar / menubar brand: `Ark.png` (copied from wulifang branding in nuke_plugins; read-only source).

Sources (copied 2026-11-01, nuke_plugins not modified):
- `nuke_plugins/wlf/assets/icons/`
- `nuke_plugins/wlf/assets/third_party/icons/ObjectID.png`
